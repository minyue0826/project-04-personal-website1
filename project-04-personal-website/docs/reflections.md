# ✍️ 读书随笔与感悟

## 📖 《所有的美好奔我而来》埃斯特·希克斯与杰里·希克斯夫妇

生活的模样，往往源于我们内心的状态。书中阐释的吸引力法则提醒我，不要沉溺焦虑、反复纠结烦恼。与其抱怨现状，不如稳住心态，怀抱正向的期待。

很多时候我们苦于困境，是注意力一直停留在缺憾之上。学着接纳自己，放下精神内耗，保持平和积极的心境，慢慢就会发现，那些期待的温暖与光亮，正一步步向自己靠近。

> 心向暖阳，美好自会奔赴而来。

---

## 📖 《思考，快与慢》丹尼尔·卡尼曼

这本书让我重新认识了自己的思维方式。丹尼尔·卡尼曼将大脑分为直觉驱动的“快思考”和理性审慎的“慢思考”。

日常生活里，我们总习惯依赖直觉快速判断，却常常忽略直觉自带的偏见与盲区。这本书提醒我，很多失误并非粗心，而是思维模式带来的局限。

遇事不能下意识仓促下定论，适时调动理性思考，主动审视自身判断，才能减少认知偏差，做出更加客观理智的选择。

---

## 📖 《人间有味是清欢》林清玄

“雪沫乳花浮午盏，蓼茸蒿笋试春盘。人间有味是清欢。”

年少时读苏轼这句词，只觉平淡；如今合上林清玄先生的书，才懂了这份清淡的欢愉。它不是寡淡，而是历经喧嚣后，对简朴生活最温柔的深情。

在这个以浊为欢的时代，清欢其实是一场生命的减法。它无需逃离尘世，只需在浮躁中守住心底的一方净土。哪怕只是静静品一壶茶，读几页书，只要心是澄明的，处处皆是清欢。

>人间至味，愿我们都能留住一颗琥珀般清透的心。
