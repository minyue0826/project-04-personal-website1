# 📚 我们的私人书单

这里是我们精选的、读过之后觉得受益匪浅的好书推荐：

| 书名 | 作者 | 推荐理由 |
| :--- | :--- | :--- |
| 《所有美好奔我而来》 | 埃斯特·希克斯、杰里·希克斯 | 如果你时常陷入精神内耗、对未来感到不安，不妨翻开此书。它引导我们接纳自我、校准内心的磁场，你是什么状态，就会遇见什么样的生活，美好自会奔你而来。 |
| 《思考，快与慢》 | 丹尼尔·卡尼曼 | 作为诺贝尔经济学奖得主的经典作品，它深入拆解人类思维模式。我们常常被直觉左右做出草率决定，读完此书，能够认清自身思考的局限，学会冷静思考，做出更加清醒客观的决策。 |
| 《人间有味是清欢》 | 林清玄 | 当代散文大家林清玄的经典精选集，书名化用自苏轼的千古名句，书中他以细腻温婉的笔触，将禅意与人生哲理巧妙融于草木茶饭、日常点滴之中。在喧嚣浮躁的现代社会里，林清玄用文字引导我们放慢脚步，以清净澄明的心去感知世界。 |
